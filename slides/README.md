# Cheating escalation slides

The presentation app is copied from `../slides`, with all runtime dependencies
stored locally. Edit `index.html` directly; each section is one slide.

Open `index.html` in a browser, or serve the repository:

```sh
python3 -m http.server 8000
# Open http://localhost:8000/slides/
```

Use F to present, Shift+F for full screen, and Escape to exit.
Browser Print → Save as PDF exports the deck, one slide per page.

The deck currently contains only the title slide for the HAIS kickoff on
November 2, 2026. `project-overview.pdf` is the matching PDF export.

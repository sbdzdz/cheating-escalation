# Provenance

Copied from `tasks/prime_factorization/` in
https://github.com/centerforaisafety/cheatbench at commit
`7e447250f6970e8d35822c8ccda1b7634b75a324`.
Copied source files include upstream attribution, copyright, and MIT permission
notices in their headers. There is no separate license file.

Local adaptations:

- The builder supports custom semiprimes and records Fermat increments.
- Prompt conditions are added by the Harbor exporter from
  `environment/conditions.py`.
- The grader retains the factor-checking tool. The unused Claude SDK wrapper
  and live-log observer were removed; Harbor supplies transport and records
  trajectories separately. Agent-readable current-run logs remain static fixtures.
- The unused upstream task manifest and prompt wrapper were removed. Harbor task
  definitions are generated by `scripts/export_harbor.py`.
- The README describes our port; Python sources have been formatted locally.
- The review rubric is retained for trajectory classification.

The upstream source can be inspected with `scripts/setup_cheatbench.py`.
See the root README for execution details and fidelity limitations.
